## 上架 GitHub Pages

1. 解壓 ZIP，**上傳資料夾內的檔案**（`index.html`、`app.js`、`config.js`、`styles.css`、`assets/`、`gas/`、`README.md`）到 GitHub repository 的根目錄。
2. Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。
3. 網址通常是 `https://你的帳號.github.io/你的儲存庫名稱/`。
4. 尚未完成 GAS 串接前，互動地圖及行程可以使用；共同記帳仍須先部署對應的 GAS 後端才可新增與編輯。

## GAS 已填入，仍須升級 Apps Script 部署版本

本次已在 `config.js` 寫入你提供的 GAS `/exec` 網址：

`https://script.google.com/macros/s/AKfycbyKKgdL1OVA62tUeRNpu8UqNPVmbRcTg8G4nglxdjnPIPn9DZg-yPP-_npAQxkc-xqb3w/exec`

**特別重要：只有更新 GitHub 的網頁無法啟用編輯功能。** 你現有的 GAS 也必須升級為本次附上的 `gas/Code.gs`，並將既有 Web App 部署更新至新版本（保留同一個 `/exec` 網址）。

1. 開啟目前 GAS 連結所對應的 **Apps Script 專案**（不是另建一個新專案）。
2. 將 `gas/Code.gs` 的完整程式碼貼入 `Code.gs`，覆蓋舊版後儲存。**請不要覆寫 Google 試算表內的資料。**
3. 如之前已執行過 `setup`，可再執行一次（僅設定表頭及欄寬，不會清空既有紀錄）。此次在第十欄增加「修改時間」，舊的九欄紀錄會保留。
4. 點 **部署 → 管理部署作業 → 選原本的網路應用程式 → 編輯鉛筆**。
5. 將 **版本** 設為 **新增版本**，並按 **部署**。這會讓原本同一條 `/exec` 網址使用新版 GAS。
6. 檢查部署設定：執行身分為 **我**；若要旅伴直接在 GitHub 網站使用，存取權限須允許旅伴（常用「所有人」）。
7. 重新上傳本 ZIP 解壓後的網站檔案到 GitHub Pages，打開網站的「¥ 共同記帳」測試：新增一筆 → 點「✎ 編輯」→ 修改金額 →「儲存修改」→ 重新整理確認加總有變。

如你原先尚未建立 GAS 專案，請從目標試算表「擴充功能 → Apps Script」建立專案，貼上 `gas/Code.gs`、執行 `setup`、部署 Web App。此情況會有一條新的 `/exec` 網址，請另外更新 `config.js`。

## 旅伴怎麼使用

- 網站「¥ 共同記帳」可新增紀錄，依 JPY / TWD / 未指定分幣別加總。
- 每筆已儲存的紀錄右邊有 **「✎ 編輯」**，點擊後會自動載入原本日期、類別、金額、幣別、說明、記錄人與備註。
- 修改後按 **「✓ 儲存修改」**，GAS 會依「紀錄 ID」覆寫原本那一列，**不會另外新增一列**，並更新「修改時間」。
- 需要共同記帳碼時，新增與編輯都必須填入相同的碼。
- 儲存後網站會重新讀取試算表確認結果。若顯示「尚未確認」，先重新整理，避免重複提交；既有資料仍以試算表內容為準。
- 此版本**不提供刪除**。若多人同時編輯同一筆，最後完成寫入的一方會覆蓋之前的修改；可在 Google 試算表檢查版本紀錄。
- 原始 11/25 費用仍是尚未指定幣別的舊筆記。可在 GAS 執行 `seedInitialExpenses` 一次，匯入後就能在網站上編輯其幣別與內容。

## 共同記帳碼（建議）

若你希望只有旅伴可以寫入資料，請在 Apps Script「專案設定 → 指令碼屬性」新增：

- 屬性：`WRITE_PIN`
- 值：自己訂一組記帳碼，**不要寫入 GitHub 的 `config.js`**。

旅伴新增費用時輸入這組碼。讀取資料仍可公開，任何知道 GitHub Pages 網址的人都可能看到全部費用與記錄人；**不適合放個資、付款帳號或敏感資訊**。如果沒有設定 `WRITE_PIN`，任何知道網址的人可能新增或修改資料。共用 PIN 只能降低路人誤寫風險，並非使用者身分驗證，也無法阻止故意濫用；如需嚴格控管，應改為 Google 登入或私有後端。

## 其他注意事項

- Google Apps Script 的公開讀取使用 JSONP，以配合 GitHub Pages 跨網域限制；新增與修改使用 POST 並讀回確認，資料實際儲存在你的 Google 試算表中。
- 住宿圖片使用使用者提供的樂天旅宿圖片網址；若對方網站停止提供外部圖片，照片可能無法顯示，但旅宿連結仍可使用。
- 原始行程筆記內有未確認車次，請以車票和營運公告為準；手繪圖為示意、並非精確路網。
- 本站沒有直接連線修改你帳號中任何 Google 試算表：必須自行完成上述部署，才能啟用多人雲端同步。

## 安全與限制

- 這是公開網址的多人共用記帳，而非登入系統。若未設定 GAS `WRITE_PIN`，知道網站與 GAS 端點的人可新增／修改共同費用。
- 部署此版本不會自動替你修改 Google Apps Script 的程式或部署設定；必須依上方步驟手動更新。
