# 202612 信州行｜互動旅遊地圖 + Google 試算表多人記帳

本網站可直接放在 GitHub Pages，無需 Node、伺服器或付費 API。背景圖片、六城市發光互動區、11/25–12/02 行程均已更新。

長野 11/26–11/30 住宿統一為 **Chisun Grand Nagano（チサングランド長野）**，含樂天旅宿照片、飯店資訊與 Google Maps 連結。川崎、成田的住宿不受影響。

## 上架 GitHub Pages

1. 解壓 ZIP，**上傳資料夾內的檔案**（`index.html`、`app.js`、`config.js`、`styles.css`、`assets/`、`gas/`、`README.md`）到 GitHub repository 的根目錄。
2. Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。
3. 網址通常是 `https://你的帳號.github.io/你的儲存庫名稱/`。
4. 尚未完成 GAS 串接前，互動地圖及行程可以使用；共同記帳只會顯示示範／舊筆記，無法線上儲存。

## 啟用 Google 試算表多人記帳

**重要：這部分要由有權限的 Google 帳號親自完成授權和部署。ChatGPT 無法替你授權自己的試算表。**

1. 使用自己的 Google 帳號建立空白 Google 試算表（例如「202612信州行共同旅費」）。
2. 在試算表上方選「**擴充功能 → Apps Script**」。
3. 刪除預設程式碼，把本站 `gas/Code.gs` 的內容**全部貼入**並儲存。
4. 在 Apps Script 的函式下拉清單選 `setup`，按「執行」，依提示授權。回到 Google 試算表會看到「共同費用」工作表。
5. （選用）要匯入 11/25 舊筆記，執行 `seedInitialExpenses` **一次**。會新增住宿 92,240、交通 28,030，幣別記為「未指定」；未確認前不應併入日圓或台幣總額。重跑不會重複匯入。
6. Apps Script 點「**部署 → 新增部署作業**」，類型選「**網路應用程式**」，「**執行身分**」選 **我**，「**誰可以存取**」選 **所有人（Anyone）**，點「部署」。
7. 複製網址（通常是 `https://script.google.com/macros/s/.../exec`，**要 `/exec`、不是 `/dev`**）。
8. 編輯網站根目錄的 `config.js`：

   ```js
   window.TRIP_CONFIG = {
     gasWebAppUrl: 'https://script.google.com/macros/s/你的部署ID/exec'
   };
   ```

9. 把改好的 `config.js` 重新上傳 GitHub，等 Pages 部署完成。
10. 開啟網站 → **¥ 共同記帳** → 新增一筆小額測試 → 確認工作表新增一列 → 在另一台手機重新整理查看。

**注意：每次修改 `gas/Code.gs`，需到 Apps Script「部署 → 管理部署作業 → 編輯 → 版本：新增版本」重新部署，網站才會使用更新的 GAS。** 修改 `app.js` / `config.js` 只需更新 GitHub。

## 旅伴怎麼使用

- 在互動地圖點「¥ 共同記帳」即可看到共同費用列表。
- 填日期、類別、金額、幣別、項目、付款／記錄人，按「儲存到 Google 試算表」。
- 儲存後會讀回試算表確認；如果顯示「尚未確認」，**先按重新整理，不要立刻再送一次**。
- 所有人都可以點「重新整理」讀取新紀錄，分 **JPY / TWD / 未指定** 自動加總（不將不同幣別混算）。
- 網站目前是**新增及瀏覽**，沒有刪除或編輯功能；管理者可直接在 Google Sheet 修正資料。

## 共同記帳碼（建議）

若你希望只有旅伴可以寫入資料，請在 Apps Script「專案設定 → 指令碼屬性」新增：

- 屬性：`WRITE_PIN`
- 值：自己訂一組記帳碼，**不要寫入 GitHub 的 `config.js`**。

旅伴新增費用時輸入這組碼。讀取資料仍可公開，任何知道 GitHub Pages 網址的人都可能看到全部費用與記錄人；**不適合放個資、付款帳號或敏感資訊**。如果沒有設定 `WRITE_PIN`，任何知道網址的人可能新增資料。共用 PIN 只能降低路人誤寫風險，並非使用者身分驗證，也無法阻止故意濫用；如需嚴格控管，應改為 Google 登入或私有後端。

## 其他注意事項

- Google Apps Script 的公開讀取使用 JSONP，以配合 GitHub Pages 跨網域限制；新增使用 POST 並讀回確認，資料實際儲存在你的 Google 試算表中。
- 住宿圖片使用使用者提供的樂天旅宿圖片網址；若對方網站停止提供外部圖片，照片可能無法顯示，但旅宿連結仍可使用。
- 原始行程筆記內有未確認車次，請以車票和營運公告為準；手繪圖為示意、並非精確路網。
- 本站沒有直接連線修改你帳號中任何 Google 試算表：必須自行完成上述部署，才能啟用多人雲端同步。
